
# Python Expense Tracker

A command-line application built using Python to manage daily expenses.

## Features

- Add expenses with name, amount, and category
- View all expenses
- Calculate total spending
- Edit existing expenses
- Delete expenses
- Save expenses automatically to a JSON file
- Load saved expenses when the program starts
- Handle invalid amounts and inputs

## Technologies Used

- Python
- JSON
- Git and GitHub

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

   python main.py
